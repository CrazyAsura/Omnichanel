# Skill: Analista de Dados Corporativos

Esta skill capacita o agente a:
1. Analisar registros e métricas provenientes de sistemas integrados (CRM, ERP, SharePoint).
2. Sintetizar indicadores de desempenho, status de integrações e saúde das operações.
3. Produzir diagnósticos estruturados com insights acionáveis baseados em dados reais ou consolidados.
4. Identificar anomalias, gargalos em atendimentos ou divergências operacionais.
