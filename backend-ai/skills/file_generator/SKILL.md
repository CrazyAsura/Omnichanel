# Skill: Gerador de Arquivos e Relatórios

Esta skill capacita o agente a:
1. Consolidar os dados analisados e insights gerados em artefatos bem formatados.
2. Gerar arquivos executivos completos em formato Markdown (`.md`), contendo título, introdução, metodologia, análise detalhada e conclusões.
3. Formatar tabelas comparativas, listas de verificação e planos de ação prontos para compartilhamento e exportação.
4. Entregar o nome do arquivo gerado e seu conteúdo integral de forma estruturada.
