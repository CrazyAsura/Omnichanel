# Contrato de Integração de Sistemas Parceiros

## Objeto
Este contrato estabelece as condições técnicas e jurídicas para o intercâmbio de dados via API REST e mensageria gRPC entre os parceiros comerciais e a plataforma Omnichannel.

## Cláusulas Principais
1. **Disponibilidade (SLA)**: A taxa de disponibilidade mínima garantida é de 99,9% mensal.
2. **Taxa Limite de Requisições**: 500 requisições por minuto por chave de autenticação.
3. **Criptografia**: Todo tráfego deve trafegar estritamente sob TLS 1.3 ou mTLS no canal gRPC.
4. **Vigência**: O contrato vigora por 24 meses renováveis tacitamente.
