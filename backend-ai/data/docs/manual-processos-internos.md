# Manual de Processos Internos - Omnichannel S.A.

## 1. Visão Geral
A plataforma Omnichannel unifica os canais de atendimento (WhatsApp, Chat Web, E-mail, CRM e ERP) em uma única esteira operacional.

## 2. Regras de Atendimento
- O tempo médio de primeira resposta (SLA) para solicitações prioritárias é de até 5 minutos.
- Casos complexos devem ser encaminhados ao segundo nível através do CRM corporativo.
- Toda comunicação com clientes deve registrar protocolo gerado automaticamente.

## 3. Segurança e Sigilo
- Nenhum colaborador deve compartilhar credenciais de acesso ou chaves de API.
- Todo acesso administrativo deve contar com autenticação multifator (MFA).
- Documentos confidenciais só podem ser exportados com prévia autorização do comitê de segurança.
